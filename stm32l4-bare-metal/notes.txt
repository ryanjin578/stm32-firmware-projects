5) time and timers
    registers
	PSC (prescaler) -> how fast the counter ticks
	    f_tick = f_clk / (PSC + 1)

	ARR (auto reload register) -> how high the counter goes before wrapping
	    a) CNT counts starting from 0
	    b) hits ARR
	    c) resets to 0
	    d) fires update event (interrupt flag UIF)
	    period = ARR + 1 ticks

	combined -> f_update = f_clk / ((PSC + 1) (ARR +  1))

general:
    literals
	0b -> binary
	0x -> hex
	0 -> octal
    
    *each hex digit maps to exactly 4 bits, just write hex val in binary

    '->' ex. GPIOA->MODER shorthand for (*GPIOA).MODER

    volatile -> value of variable can change outside the code, rw from mem every time
	volatile uint32_t *p -> the DATA that p points to is volatile
	    address can be cached, variable value cannot
	uint32_t * volatile p -> the POINTER itself is volatile
	    address cannot be cached, variable value can
	    compiler must reread which address holds p every time
	
	*volatile applies to whatever is immediately left of it or right if nothing is on the left

    pointer variables -> stores address, type tells the compiler what type to expect
