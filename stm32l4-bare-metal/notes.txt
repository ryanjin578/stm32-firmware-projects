    AHB/APB buses
	AHB (adv hi-perf bus) -> fast bus
	APB (adv peripheral bus) -> slower, connects to AHB through bridge

	*each bus has its own RCC enable register

    	Cortex-M4 core
  	    │  STR instruction: address 0x4000002C, data 999
      	    │  Address is in the peripheral region, so it goes out the core's S-bus
      	    ▼
    	AHB bus matrix
      	    │  Decodes the address, routes the transfer to the AHB1 bus
      	    ▼
    	AHB1 bus  (clocked by HCLK)
      	    │  Address decode selects the AHB/APB1 bridge
    	    ▼
    	AHB/APB1 bridge
      	    │  AHB slave on one side, the only APB1 master on the other
      	    │  Converts the transfer to the APB protocol, re-timed to PCLK1
      	    ▼
    	APB1 bus  (clocked by PCLK1)
      	    │  Setup phase:  address, write signal and data driven, TIM2 selected
      	    │  Access phase: enable asserted, transfer completes
      	    ▼
    	TIM2
             Decodes offset 0x2C and latches 999 into ARR
             (into the preload copy if ARPE = 1, otherwise straight into the active ARR)

5) time and timers
    f2 (systick) -> counter built into CPU that counts RCC clock's pulses
	24 bits, counts down
	STK_LOAD register -> specifies the start value to load into register when 0

    f3 (tim2) -> systick can at most run one period, if we need multiple periods at once we use timx
	UEV -> update event -> rollover event when counter hits upper limit
	UIF -> update flag -> set when rollover event occurs, cleared by software

    registers
	preload (copy) -> handles writes while keeping another copy running, copied into shadow
			  at next UEV

	PSC (prescaler) -> how fast the counter ticks
	    f_tick = f_clk / (PSC + 1)

	ARR (auto reload register) -> how high the counter goes before wrapping
	    a) CNT counts starting from 0
	    b) hits ARR
	    c) resets to 0
	    d) fires update event (interrupt flag UIF)
	    period = ARR + 1 ticks

	combined -> f_update = f_clk / ((PSC + 1) (ARR +  1))	
		    (PSC + 1)(ARR + 1) = f_clk / f_interrupt

general:
    literals
	0b -> binary
	0x -> hex
	0 -> octal
    
    *each hex digit maps to exactly 4 bits, just write hex val in binary

    '->' ex. GPIOA->MODER shorthand for (*GPIOA).MODER

    volatile -> value of variable can change outside the code, rw from mem every time
	volatile uint32_t *p -> the DATA that p points to is volatile
	    address can be cached, variable value cannot
	uint32_t * volatile p -> the POINTER itself is volatile
	    address cannot be cached, variable value can
	    compiler must reread which address holds p every time
	
	*volatile applies to whatever is immediately left of it or right if nothing is on the left

    pointer variables -> stores address, type tells the compiler what type to expect

    RM0351 register access codes
    +--------+---------------------------+----------------------------------+
    | Code   | Read                      | Write                            |
    +--------+---------------------------+----------------------------------+
    | rw     | returns current value     | sets the value                   |
    | r      | returns current value     | ignored                          |
    | w      | not meaningful            | 1 triggers an action             |
    | rc_w0  | returns current value     | 0 clears the bit, 1 no effect    |
    | rc_w1  | returns current value     | 1 clears the bit, 0 no effect    |
    | rc_r   | returns value, then clears| ignored                          |
    | rs     | returns current value     | 1 sets the bit, 0 no effect      |
    | Res.   | reserved                  | keep at reset value              |
    +--------+---------------------------+----------------------------------+
